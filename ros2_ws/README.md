# Bomba ROS 2 Humble Navigation Package

This package bridges your robot hardware (Lidar, wheel encoders/odometry, gas sensors) to the Bomba Dashboard web application via Rosbridge.

## Architecture & Topic Mapping

| System Topic | Dashboard Connection | Purpose |
| :--- | :--- | :--- |
| `/scan` | Lidar sensor input | LaserScan feed consumed by SLAM Toolbox and Nav2 costmaps |
| `/odom` | Robot base odometry | Raw wheel odometry input to EKF filter |
| `/odom_filtered` | Robot state filter | Fused odometry output from robot_localization |
| `/cmd_vel` | Manual drive / Nav2 output | Velocity commands sent to base motor controller |
| `/map` | MapView component | 2D Occupancy grid generated by SLAM Toolbox |
| `/goal_pose` | ManualControl component | Nav2 navigation target dispatched from dashboard |
| `/planned_path` | MapView component | Global navigation trajectory mirrored from `/plan` |
| `/sensor/methane` | SensorGrid component | Real-time CH4 telemetry (ppm) |
| `/sensor/flammable` | SensorGrid component | Real-time flammable gas telemetry (% LEL) |
| `/sensor/air_quality` | SensorGrid component | Real-time air quality index (AQI) |

## Quick Start on Linux (Ubuntu 22.04 with ROS 2 Humble)

1. Make the dependency installation script executable and run it:
   chmod +x install_dependencies.sh
   ./install_dependencies.sh

2. Build the workspace:
   colcon build --symlink-install

3. Source the environment:
   source /opt/ros/humble/setup.bash
   source install/setup.bash

4. Launch the entire system:
   ros2 launch bomba_nav2 bomba_system.launch.py

5. Start the Bomba Next.js Dashboard:
   npm run dev
